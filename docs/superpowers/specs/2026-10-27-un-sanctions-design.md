# 国連制裁監視

2026-10-27、公式XMLと制裁委員会更新発表の二重監視方式をユーザー承認。

目的は国連の個人・団体指定を財務省等とは独立して検知し、根拠を保持すること。
決議だけの監視では委員会による変更を見逃す。XMLだけでは変更理由の確認に弱い。
公式統合リストXMLと現役の全制裁委員会の発表一覧を監視する。

- Permanent Reference Numberを対象者IDとし、DATAID、制度、掲載日、原語表記、別名品質、原本、SHA256を保持する。
- 初回はbaselineとして区別。すべてのmaster反映はsnapshotに固定した明示的レビューと適用操作が必要。Low quality aliasは通常masterに入れない。
- 名称ではなく対象者IDと全属性で差分を計算。削除・別名減少もレビュー対象。国連由来だけを変更し、他ソース・過去行を残す。
- 原本、HTTP状態、最終確認、元データ日時、ETag/Last-Modified、件数、差分、取得/構造異常を記録。失敗時は有効snapshotとmasterを維持し、エラー状態と証跡を公開。
- 各委員会発表は独立センサー。新着は要確認とし、XML未更新を正常完了としない。発表本文や決議は参照根拠であり、自動的な国内適用判断には使用しない。
- 指定船舶は統合XMLの対象外。別枠参照先として明記し、船舶まで網羅したと表示しない。
- 公式配布URLのリダイレクト先は観測した公式ホストに限定。一時署名queryは公開証跡から除去。
- GitHub Actionsは15分間隔、既存commit concurrencyに参加。失敗も記録し、通知配信は既存設定に従う。
- Google Sheets向けstatusに国連XML/委員会発表を追加。専用レビューCSVを提供し、既存ソースの候補表示を消さない。

自動master反映、船舶の名称master混在、アクセス制限の回避は対象外。
